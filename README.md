# 🧠 Emotional Intelligence - MMCOE

[![Python](https://img.shields.io/badge/Language-Python-blue.svg)](https://www.python.org/)

## 📌 About The Project

This repository contains the source code and supplementary materials for the program conducted under the **SPPU QIP (Savitribai Phule Pune University - Quality Improvement Program)** on **"Emotional Intelligence"** at **MMCOE** (Marathwada Mitra Mandal's College of Engineering) in **March 2026**.

The core of this repository is a Python application designed to demonstrate, analyze, or facilitate activities related to the concepts discussed during the program.

## 📂 Repository Structure

* `app.py`: The main Python application or script.
* `README.md`: Project documentation.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Ensure you have Python installed. You can download it from [python.org](https://www.python.org/).

### Installation & Execution

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/mituskillologies/emotional-intelligence-mmcoe.git](https://github.com/mituskillologies/emotional-intelligence-mmcoe.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd emotional-intelligence-mmcoe
    ```

3.  **Run the application:**
    Execute the Python script using the following command:
    ```bash
    python app.py
    ```
    *(Note: If `app.py` is built using a framework like Streamlit, you would run it using `streamlit run app.py` instead. Ensure any required dependencies are installed beforehand.)*
